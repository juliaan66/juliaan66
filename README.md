### 🚀 Proyectos destacados

#### 🐪 GAZMULA — Vacaciones en Paz
App de escritorio para gestionar el programa de acogida de niños saharauis en verano en la provincia de Cádiz.
- Electron + React + TypeScript, con base de datos local (sql.js) que **funciona sin internet**.
- Servidor central en Node.js + Express + SQLite con autenticación JWT y sincronización sin pérdida de datos.
- Rellena automáticamente los anexos oficiales en **PDF** (jsPDF) y exporta documentos a Excel y `.zip`.
- Cuentas para admin y municipios, con logo y nombre propio para cada asociación.

#### 📅 Calendario Local
Calendario personal para Windows, sin cuentas ni nube, que se suscribe desde el iPhone.
- Servidor en **Python** que publica un feed `.ics` en la red Wi-Fi (conexión por QR).
- Vistas de día, semana, mes y año; eventos repetidos (RRULE/EXDATE) e importación/exportación `.ics`.
- Avisos con **notificaciones nativas de Windows** (posponer / descartar) aunque la ventana esté cerrada.
- Tema claro/oscuro y se abre como app propia con un icono que muestra la fecha del día.
